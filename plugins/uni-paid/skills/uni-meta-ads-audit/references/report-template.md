# Report skeleton

Distilled from the last three UNI Meta prospect audits (Nov 2026), which converged on the same shape. Notion markdown by default. Hyphens only. One blank line around every heading, table and list.

---

## Header callout (always)

```
**YYYY/MM/DD** | Ad account <id> (<account name>)
Data sources: Ads Manager + Events Manager [+ store figures as shared on <date>]
<window> (90 days), deep-dive on the last 30 days. Attribution: <setting(s) as set per campaign>
Not included: <e.g. LTV, incrementality>
```

## Sections, in order

| # | Section | Contents |
|---|---|---|
| 0 | Background | 2 to 4 sentences: what the brand sells, current spend level, the questions this audit answers |
| 0 | Summary | 4 to 6 numbered findings, bold lead sentence each, one supporting number each. Finding 1 is usually "Tracking is / is not the problem" |
| 1 | SETUP - Tracking | Current (check / cross list) then Suggestions (one short paragraph, effort in days) |
| 2 | CAMPAIGN - Stats | 4-week block table + 90-day total callout + "What the numbers say" bullets |
| 3 | FREQUENCY - Reach | Weekly table + age band table + bullets |
| 4 | TRAFFIC COST | First vs last week table + placement table + bullets |
| 5 | CREATIVE | Concept table, video table (hook / hold / CTR), new-launch readout, bullets |
| 6 | STRUCTURE | Campaign or ad set table with status and learning state + bullets |
| 7 | SITE / FUNNEL | Step table with peer percentile + live page findings + offer math |
| 8 | AUDIENCE - Geo and demo | Only if it changes a recommendation; otherwise fold into Stats |
| 9 | ATTACK PLAN | Risk callout, then Step 1 to Step 5 (see SKILL.md Step 5). Each step: "Addresses finding N" |
| 10 | Process | Day / week milestones |
| 11 | Pricing (prospect only) | Placeholder only: [pricing from UNI Service Catalog - Sean] |
| 12 | Next Steps | 3 to 4 numbered items, meeting link |

## Writing rules that held up

- Lead every section with the table, then say what it means. Never the reverse.
- Name the variable that moved. "CPM +55% while CTR stayed flat" beats "costs went up".
- Say what is not the problem as clearly as what is. Clients arrive with a theory; address it.
- Label small samples: under 5 purchases is directional, under 1x CPA spend is no verdict.
- One evergreen structure code block, budget shares as percentages, no SKU-level detail.
- Client mode drops Pricing and the case-study pitch; keeps everything else.
