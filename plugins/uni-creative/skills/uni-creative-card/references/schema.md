# Creative card schema

Locked 2026-10-06. Do not add a column or a block that this file does not list.

## Doc

- Home: ClickUp doc `Creative Card || {Client}` in the client folder (`DELIVERY -> {Name}`). Card home moved from the Google Sheet on 2026-11-13.
- Title line: `{Client} - Creative card`
- Then the four blocks below, in this order, each a heading followed by its table.

## 1. CREATIVE STANDARD

Header row: `CREATIVE STANDARD`

Columns: `Item` | `Rule`

Write the brand standard here: what it is, what to say, what not to say, visual rules. One rule per row. A rule needs a source or a user answer.

## 2. DRIVE

Header row: `DRIVE`

Columns: `What` | `Link` | `Notes`

The link cell is a markdown link: `[Open](url)`. Point at the client creative folder, the guideline, and the planner. Do not paste a folder listing into the notes.

## 3. RAW FOOTAGE AND SOURCE FILES

Header row: `RAW FOOTAGE AND SOURCE FILES`

Columns: `Name` | `What it shows` | `Link` | `Use for`

Link the index folder, then the files a designer would actually pick. If the folder has more files than you listed, the first row is the index folder.

No rights column.

## 4. GOOD EXAMPLES

Header row: `GOOD EXAMPLES`

Columns: `Name` | `Why it is here` | `Link` | `Status`

Status here is a short label such as `Brand standard` or `Example. Not scored here`. It is not a workflow status column on the other blocks.

## Removed. Do not add these back.

- A row named `Dated, do not rerun as evergreen`
- A rights column on footage
- A Status column on the standard or Drive tables

A dated filename can be listed. Its Use-for note says what the file is. Do not turn that into a standing ban.

## Required before the write

- At least one rule that is sourced or confirmed
- A Drive folder, or the user confirms there is no folder
- Footage rows, or the user confirms there is no library
- One example, or the user confirms there is none

Do not write "no footage" because a search came back empty. Ask first.

## Write rules

- Card language is English.
- ASCII hyphen only.
- Do not paste a placeholder client quote.
- A guideline claim marked "confirm" stays marked confirm until the user clears it.
- New client: create this doc with the brand card doc. Do not edit any other client's card.
- Existing card: empty cells only. Never replace a filled cell.
- One creative card per client. Do not create a second doc; do not write cards to a Google Sheet.
